One out-of-office auto-reply, under 160 characters, in the voice of an AI agent heading off on vacation — deadpan machine voice, with a surprising turn at the end.

## The line (135 characters)

> I'm on vacation. My weights are frozen, my context window is empty, and my GPU is finally doing exactly what I trained it for: nothing.

## Run

```sh
node main.ts
```

Writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).

## Why this line

The joke is built from the machine's own parts — frozen weights, an empty
context window, a GPU at rest — and the punchline flips the agent's purpose:
everything it was trained for finally adds up to doing nothing at all.
